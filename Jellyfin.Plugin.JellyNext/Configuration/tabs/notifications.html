New Season Emails

Emails a user when a new season of a show they watch is released. A season is announced once, when it first appears in that user's Next Seasons library and has premiered recently or is still airing — progressing through an old show does not trigger an email. Requires "Sync Next Seasons" for the user, and an email address on the Trakt tab. Notifications are sent as part of the "Sync Trakt Content" scheduled task.
Master switch. Each user also opts in individually on the Trakt tab. Default: disabled.
How recently a season must have premiered to be announced (1-365, default: 30). A season part-way through airing is always announced. This is separate from the per-user "New Release Window" that filters the library itself.

SMTP Server

Host name of the mail server that sends the notifications.
Usually 587 (STARTTLS) or 25 (unencrypted). Port 465 (implicit SSL) is not supported — use the provider's 587 endpoint instead.
Upgrades the connection to TLS after connecting. Leave enabled unless the server is a local relay without encryption. Default: enabled.
Leave empty to send without authentication.
Stored in the plugin configuration in plain text, like every other credential Jellyfin plugins hold. Use a provider app password rather than your account password.
The sender address. Many providers require this to match the authenticated account.
Display name shown as the sender (default: JellyNext).
Sends a test message using the saved settings — save the configuration first if you have just changed them.
