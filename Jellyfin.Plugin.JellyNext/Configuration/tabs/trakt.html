Trakt Connection

Trakt's free tier allows one connected community app per account, counted by OAuth client ID. If you also run the official Jellyfin Trakt plugin, a free account cannot connect both under their own client IDs. These modes let JellyNext present itself as the same app as the Trakt plugin.
Trakt refresh tokens are single-use and rotate on every refresh, so only one plugin may refresh. When enabled, JellyNext refreshes the expired token and immediately writes the rotated pair back into the Trakt plugin's configuration, keeping it the sole holder of valid tokens. When disabled, JellyNext skips the sync cycle and waits for the Trakt plugin to refresh on its own — but note the Trakt plugin only refreshes when it makes a call (scrobbling or its library sync task), so a token may stay expired for a long time on an idle server. Default: enabled.
