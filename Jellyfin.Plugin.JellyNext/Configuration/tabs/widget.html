New Seasons Widget

Adds a row to the Jellyfin home screen listing the shows the signed-in user has a new season of, each with a Request button that sends the season to the download integration configured on the Downloads tab. It shows the same seasons as that user's Next Seasons library — including their "New Release Window" filter — so no extra Trakt requests are made, and it needs Sync Next Seasons enabled for the user.
Jellyfin has no supported way for a plugin to add code to the web interface, so enabling this adds a script tag to the web client's index.html. Turning it off removes the tag again. Jellyfin needs write access to its web directory; if it does not have it, the widget silently does not appear and a warning is written to the log. Reload the web page (Ctrl+F5) after changing this. Default: disabled.
The heading shown above the row (default: New Seasons).
How many shows the row holds, most recently premiered season first (1-50, default: 12). The row scrolls sideways, so a larger number is not wider — it is just further to scroll. Cards are drawn at the same size as Jellyfin's own home screen rows.
Where the row sits among Jellyfin's own home screen sections (default: below, so the widget does not push Continue Watching down the screen).

Check Artwork

Reports what the server resolved for each card of the selected user: whether the show and the season were matched in your library, which images those items hold, the paths the card loads, and which step of the chain — the library season, your metadata providers, the library show, or Trakt — the picture actually came from. A card showing only the show's name means every one of those came back empty, and this says which step did.
