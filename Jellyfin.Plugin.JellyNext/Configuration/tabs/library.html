Mark JellyNext Items

Once Jellyfin has scanned them, JellyNext's placeholders look exactly like the media the server really holds — which is the point on a TV or phone app, where playing one is the only way to ask for a download, and misleading everywhere else. These settings put a tag on those items and, in the web interface, a badge on their cards and a download icon where the play icon would be.
Writes the tag below onto every movie, show, season and episode in JellyNext's virtual libraries. Jellyfin shows tags on the item, and you can search, filter and build collections on them. Applied as items are scanned in and again after each Sync Trakt Content run; turning this off takes the tag off again on the next save. Default: disabled.
The tag written onto the items (default: JellyNext). Renaming it moves the tag on the next save — the old one is removed, so items never end up carrying both.

Web Interface

These need the tag above, and they only affect the Jellyfin web interface: Jellyfin has no supported way for a plugin to change how a native client app draws a card, so enabling either of them adds a script tag to the web client's index.html — the same one the New Seasons widget uses. Reload the page (Ctrl+F5) after changing them.
Draws a small label in the corner of the poster, and next to the title on the item's page. Default: enabled.
What the badge says. Leave it empty to use the tag itself. "Recommended" or "Request" read better than a plugin's name to the people using the server.
Purely cosmetic: the button still plays the placeholder, which is still what sends the download request. It just stops promising playback the server cannot deliver. Default: enabled.
What the item page's play button says for a tagged item (default: Request).
